# AGENTS.md — Авантюрин (aventurine_bot)

Указатель для ИИ-агентов (Codex, Claude Code). Подробности — в [README.md](README.md)
и [docs/README.ru.md](docs/README.ru.md).

## Что это

Telegram-бот модерации канала и привязанного чата обсуждения: реакции от
неподписанных, реакции от чужих каналов, журнал входов, действия после банов,
`/post` (кнопки к посту владельца). LLM-режим опционален и сейчас отложен
(нет бюджета на API).

Стек: TypeScript, grammY, Vercel (serverless webhook, бюджет 9–10 с), Upstash Redis.

## Как работать

- Ветки `claude/*` или `codex/*`, только через PR в `main`.
- **Слияние в `main` = деплой в прод** (Vercel подключён к GitHub). Сливать только
  с явного согласия владельца.
- Перед PR: `npm run verify` (typecheck + все тесты, включая сухой прогон webhook
  с поддельными Telegram/Redis — `tests/e2e/`). Как добавить сценарий —
  `.claude/skills/verify/SKILL.md`. Claude Code запускает его сам хуком Stop.
- Секреты: `.env` в `.gitignore`. В Vercel переменные sensitive —
  `vercel env pull` отдаёт `[SENSITIVE]`, настоящий `.env` только у владельца.

## Осторожно: бот банит живых людей

- Модерацию (реакции, баны, удаление) не проверять на живых чатах. Только тесты с
  подставными Telegram/Redis (`tests/`) или сухой прогон через `bot.handleUpdate`,
  где к Telegram пропускаются лишь `getChat`/`getChatMember`/`getMe`, а все
  записи перехватываются (`bot.api.config.use`). Тестовые ключи Redis удалять.
- Необратимое (удаление сообщений и реакций человека) — только по явной кнопке
  модератора (🧹), никогда автоматически, в том числе в банах по реакциям.
  **Единственное исключение** (решение владельца 2026-11-17): в чате турниров
  (`TOURNAMENT_CHAT_ID`) бот сам удаляет сообщение со ссылкой от только что
  вошедшего (≤ 15 мин) и мутит его; бан и удаление остальных сообщений — кнопками.
  Баны в чате турниров не распространяются на канал и чат обсуждения.
- Ошибка проверки подписки ≠ «не подписан»: при сомнении не банить.

## Устройство (что легко сломать)

- Порядок регистрации в `src/bot.ts` важен: `registerModerationCallbacks` —
  catch-all для `callback_query`, все остальные кнопки регистрируются **до** него.
- `src/middleware/scope.ts` решает, какие апдейты вообще доходят до хендлеров;
  новый тип апдейта или чат нужно пропустить там.
- `allowed_updates` (в `src/bot.ts`) применяются только после `/api/setup`.
- Реакции одного пользователя сериализуются замком `src/user-lock.ts`.
- Webhook должен уложиться в 9 с, иначе Telegram повторит апдейт.
